Shanghai Trip 2026–2027 — เว็บไซต์สำหรับเปิดดูร่วมกัน

ไม่ต้องใช้ Firebase หรือฐานข้อมูล

วิธีใช้งานบนคอมพิวเตอร์: เปิด index.html ในเบราว์เซอร์

วิธีสร้างลิงก์ด้วย GitHub Pages:
1. สมัครและเข้าสู่ระบบ github.com
2. สร้าง Repository ใหม่ชื่อ shanghai-trip และตั้งค่าเป็น Public
3. อัปโหลดไฟล์ index.html, app.js, style.css และโฟลเดอร์ images (คงโครงสร้างเดิม)
4. ไปที่ Settings > Pages > Build and deployment > Deploy from a branch
5. เลือก main และ /(root) จากนั้น Save
6. รอสักครู่ จะได้ลิงก์ https://USERNAME.github.io/shanghai-trip/

ข้อควรทราบ: ลิงก์ GitHub Pages แบบ Public ใครมีลิงก์ก็เปิดดูได้ ไม่ควรใส่ข้อมูลการจองที่เป็นความลับ
